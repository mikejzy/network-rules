# 网络规则库

集中管理手机 Surge 和软路由的分流规则。此仓库公开，任何人都可以查看其内容和历史记录。

## 目前状态

规则库已建立，暂未导入规则，也未连接到任何设备。现有手机和软路由配置不受影响。

## 以后如何添加

在这个对话里发需要处理的网站、域名、IP 或规则文件，并说明希望直连、走代理还是拦截，以及用于手机 Surge、软路由或两者。维护时会先核对规则格式和适用范围，再添加对应文件并提供可引用的链接。

可按用途和客户端整理：

- `surge/`：Surge 规则集文件。
- `openclash/`：软路由 OpenClash 规则文件；格式按实际配置和版本核对。
- 新文件按实际需要创建，规则用途和更新方式在添加时记录。

不同设备的策略名称、规则顺序、格式及更新方式可能不同。仓库更新后，需要相应设备引用规则文件并完成更新才会生效；添加引用前需检查实际配置，避免覆盖或改变已有分流。

## 公开内容注意事项

这里只放适合公开的规则及说明，不上传订阅链接、代理节点、密码、密钥、令牌、证书、私人 IP、设备完整配置或其他敏感信息。GitHub 的历史记录也会保留提交内容。
