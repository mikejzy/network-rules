# 我的直连

这是一份合并管理的直连规则，来源于公司软路由和手机 Surge 原有规则。仓库公开，任何人都可以查看内容和历史记录。

## 规则文件

[我的直连：my-direct.list](my-direct.list)

- 公司软路由原有 104 条，手机 Surge 原有 4 条。
- 两边有 2 条完全相同，合并后共 **106 条**：96 条域名后缀、10 条精确域名。
- 文件只包含匹配条件；引用时应指定 DIRECT 策略。
- 目前仅整理到仓库，尚未将设备切换到此文件；配置修改及规则顺序应先核对。

## 使用和维护

在这个对话里发需要新增或调整的网站、域名、IP 或规则，并说明用途。维护时核对格式和适用范围，再更新这份规则文件。

Surge 可将纯文本文件作为 RULE-SET 引用。Mihomo/OpenClash 使用该文件时需要支持文本规则集，并将规则提供者配置为 `behavior: classical`、`format: text`；接入前应核对设备版本和配置。设备需引用文件并更新后，仓库的改动才会生效。
