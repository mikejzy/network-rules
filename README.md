# 网络规则库

这里集中管理手机 Surge 和软路由的在线规则。仓库公开，任何人都可以查看内容和历史记录。

## 我的直连

[我的直连：my-direct.list](my-direct.list)

- 公司软路由原有 104 条，手机 Surge 原有 4 条，家里软路由原有 108 条。
- 合并并去除完全相同的规则后共 **110 条**：98 条域名后缀、12 条精确域名。
- 文件只包含匹配条件；引用时应指定 DIRECT 策略。
- 公司软路由、家里软路由和手机 Surge 配置已指向本文件；各设备可能因缓存或更新时机加载不同版本，手机实际同步及加载状态需在设备上确认。

## Whatnot

[Whatnot 在线规则：whatnot.list](whatnot.list)包含 `whatnotapp.com` 和 `whatnot.com` 两条域名后缀规则，来源于原有手机 Surge Whatnot 规则。文件不指定策略，设备引用时可选择对应的策略组。

现有手机配置中另有独立的 `cloudfront.net` 规则。CloudFront 是多服务共用的 CDN，本规则集未包含它；直播、支付及第三方服务是否完整覆盖尚未验证。

## 使用和维护

在这个对话里发需要新增或调整的网站、域名、IP 或规则，并说明用途。维护时核对格式和适用范围，再更新对应的规则文件。

Surge 可将纯文本文件作为 RULE-SET 引用。Mihomo/OpenClash 使用该文件时需要支持文本规则集，并将规则提供者配置为 `behavior: classical`、`format: text`；接入前应核对设备版本和配置。设备需引用文件并更新后，仓库的改动才会生效。
